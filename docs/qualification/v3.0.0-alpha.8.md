# IoT-MD v3.0.0-alpha.8 qualification

Status: **awaiting hardware evidence**.

This release retains the Alpha 7 native qualification requirements. Its
additional portal observations are:

- application, core and universal uploads select the correct overall workflow;
- byte upload advances when Safari reports `lengthComputable` as false;
- the current-stage percentage and overall step indicator remain distinct;
- completed stages remain visible until the page transitions to activation;
- all distinct scan results appear in the Wi-Fi selector in Safari;
- a non-visible stored SSID remains selectable as the current network; and
- manual SSID entry submits the same `wifi_ssid` field in first-boot and
  authenticated network settings;
- one transient startup association failure is retried without latching
  recovery, and three consecutive failed attempts enter the recovery path; and
- a power cycle with valid stored credentials returns to the normal portal.

Record results on physical hardware. These UI observations do not qualify the
native paired-trial, rollback, recovery or job capabilities.
