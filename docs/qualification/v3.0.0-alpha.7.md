# IoT-MD v3.0.0-alpha.7 qualification

Status: **awaiting hardware evidence**.

Host tests and a production-secure native compile verify ABI 4 registration,
contract validation, guarded OTA calls, bounded recovery state, queue limits,
structured events and compatibility fallback. These checks do not qualify the
physical recovery or rollback behavior.

Required Alpha 7 observations are:

- three incomplete product boots enter frozen recovery without importing the
  replaceable application;
- explicit recovery and watchdog recovery retain bounded reset diagnostics;
- signed recovery installation restores a bootable confirmed pair;
- confirm and rollback reject stale partition labels and non-trial states;
- successful rollback returns to the previous confirmed core/application pair;
- queue saturation fails without blocking, and event overflow remains bounded;
- a power interruption at each recovery and OTA transition leaves either the
  prior confirmed pair or a recoverable trial; and
- Release Qualification accurately separates mechanism availability from the
  recorded result of these tests.

Record actual outcomes only. Until this matrix passes, `paired_trial`,
`native_rollback`, recovery qualification and job qualification must remain
false in the native capability record.
