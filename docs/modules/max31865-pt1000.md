# MAX31865 PT1000

Use `class: sensor` and `subclass: MAX31865-PT1000`. Configure the `max31865`
object with `spi`, `sck`, `mosi`, `miso`, `cs`, `baudrate`, `wires` (2 or 3),
`filter_hz`, `rtd_nominal`, `ref_resistor`, and `precision`. Defaults target SPI
0 on GPIO 2/3/4 with CS 5, a 1 MHz bus, PT1000 and a 4.3 kΩ reference.
`pollinterval` defaults to 30 seconds.

The driver publishes temperature plus resistance, raw RTD and MAX31865 fault
diagnostics. Multiple devices may share one identically configured SPI bus but
must use distinct CS pins. See the
[single-sensor example](../../examples/module_settings.max31865_pt1000.example.json)
and [shared-bus example](../../examples/module_settings.dual_pt1000_voltage_display.example.json).
